# 库存项目 · 阶段 2：原生页面

当前参考状态：C11 完成。接续阶段 1 的库存业务规则，建立浏览器页面；本课只编辑库存。

## 运行

在仓库根目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，打开 `http://127.0.0.1:8000/examples/inventory/02-web/`。无需安装依赖。

| 文件 | 作用 |
| --- | --- |
| index.html | 带标签的搜索、分类选择、商品列表、库存表单与状态提示 |
| data.js | 与 `../../shared/products.json` 一致的固定起始数据 |
| app.js | 独立数据副本、组合筛选、事件委托、库存转换与校验、渲染和焦点恢复 |
| style.css | 基础排版、错误信息与可见焦点 |

为先学习 DOM，使用两个按顺序 defer 加载的经典脚本。筛选、统计与写入在本页用数组表达；C16 再拆成 ES 模块并复用阶段 1 的 Inventory，不提前引入包或构建工具。

数据使用商品对象与 tags 数组的独立副本。只编辑 stock，接受 0–99999 整数；名称、分类、价格、标签和 id 保持固定起始值。修改在内存中，刷新恢复。原生约束提供即时反馈，JS 解析器守住写入入口。

## 验收

- 初次打开：6 种商品、52 件、库存总价值 2634800 分（26348.00 元）。
- 分类配件：P004、P005；再搜键盘为空态。汇总始终统计全部商品。
- 恢复全部，搜索 p002：无线鼠标；点击按钮内 span 或用 Enter/Space 打开编辑。
- 把 P002 从 0 改 3：55 件、26735.00 元；改回 0 恢复起始统计。
- 空值、-1、3.8、100000 无法保存，字段错误可见；0 与 99999 可保存。
- 保存与取消后恢复编辑按钮焦点；按钮已被筛选隐藏时回到搜索框。
- 切换分类三次后按钮仍可用；取消不改库存；刷新恢复全部起始数据。

C11 浏览器验证明细见 [examples/c11](../../c11/README.md)。请求、存储和响应式布局按后续课程继续推进。
