## 为你的 Java 经验搭一座桥

你已会写程序，但不必提前掌握 HTML、CSS、浏览器或 TypeScript。课程从这些基础讲起，用 Java 熟悉的对象、集合、异常和工程经验帮助你理解 JavaScript 的不同之处。

**48 课主线已发布。** 第一次学习先到[库存工作区与 5 个 Lab](./labs/)准备自己的工程，再从 [C01](./01-history-web/c01-story-ecosystem/)开始；[学习路线](./roadmap/)保留全部课程入口和阅读进度。

语言与数据结构、Node/Bun 运行时、npm/Yarn/pnpm 包管理器会分别讲清；之后深入 React，再学习开源组件与 SAP UI5 系列。

## 同一个项目，五次阶段交付

开始前先读 [Lab 规则与验收](./labs/rules/)，查看固定商品、字段限制、操作要求和预期结果，再按下面的顺序进入阶段任务。

正常学习一直修改自己的 `inventory/`；阶段起点只用于补课或恢复，不用每天新建工程。Lab 收尾就是课程练习，不另加一套大作业。

## 每一课怎么学

<div class="home-steps">

1. **看任务，再读课文** 先看任务卡，确认起点、当前目录、本课改动和预期结果；从 Lab 步骤跳到要读的小节。
2. **先猜，再运行** 在自己的工作区跟做：先预测输出，再运行，用有帮助的 Java 对照理解差异。
3. **调试、验收、留暂停点** 按「自己尝试」收集错误证据、修复并复测，卡住后再展开提示或答案；检查当前文件，在 `notes/next.md` 留下暂停点，读懂后再主动标记课程完成。

</div>

## 两种学习节奏

<div class="pace-cards">

- **4 周主线** 每周 6 天，每天 2 课，共 24 天、48 课；每天 3–4 小时，包含 Lab 跟做与调试。适合能持续投入、希望连贯完成库存管理项目。
- **8 周慢速与深化** 每周 6 天，每天 1 课，按同样顺序推进。适合希望增加复习时间，或每天可用时间较少。

</div>
