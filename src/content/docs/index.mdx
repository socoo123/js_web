## 为你的 Java 经验搭一座桥

你已会写程序，但不必提前掌握 HTML、CSS、浏览器或 TypeScript。课程从这些基础讲起，用 Java 熟悉的对象、集合、异常和工程经验，帮你看清 JavaScript 的不同之处。

语言与数据结构、Node/Bun 运行时、npm/Yarn/pnpm 包管理器分开讲清；之后深入 React，再学开源组件与 SAP UI5 系列。

## 每一课怎么学

<div class="home-steps">

1. **从 Lab 进入课文** 在 Lab 主页选中这一课的标签，看清要改的文件和验收标准，再点「打开课文」。
2. **先猜，再揭晓** 课文里的「先猜一猜」会先遮住输出，写下你的猜测再点揭晓；练习先自己做，再分步看提示和参考答案。
3. **调试、验收、回到 Lab** 按「自己尝试」收集错误证据、修复并检查，在 `notes/next.md` 留下暂停点，回 Lab 主页继续下一课。

</div>

## 两种学习节奏

<div class="pace-cards">

- **4 周主线** 每周 6 天，每天 2 课，共 24 天、48 课；每天 3–4 小时，包含 Lab 跟做与调试。适合能持续投入、希望连贯完成库存项目。
- **8 周慢速与深化** 每周 6 天，每天 1 课，按同样顺序推进。适合希望多留复习时间，或每天可用时间较少。

</div>

两种节奏学完都接 L6 毕业挑战。按天排列的完整课表见[学习路线](./roadmap/)。
