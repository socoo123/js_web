**48 课、5 个 Lab、一个长期工作区。** 从商品卡片到静态交付，每课接续自己的修改，共用数据、规则和依赖。先准备工程，再从 [C01](/js_web/01-history-web/c01-story-ecosystem/)开始；每日安排见[学习路线](/js_web/roadmap/)。

## 第一次开始

先准备 [Node 24](https://nodejs.org/en/download)。下载 <WorkspaceDownload label="C00 初始工程" />，在新的空目录 `inventory/` 中解压；压缩包中的文件直接位于该目录，不要解压到已有作业里。已克隆仓库也可使用 `labs/inventory/`，不用安装课程网站。

在库存工作区执行一次：

```sh
npm ci
npm run lab -- start C01
npm run lab -- dev
```

打开终端打印的地址，应看到「P001 机械键盘 · 库存 12 件」。启动脚本是提供好的骨架，工具原理在运行时与工程课解释。网站本身无需本地安装。

安装会下载 React、组件库与检查工具，用时取决于网络和缓存。首次使用 OpenUI5 时，UI5 CLI 还会下载对应框架资源。其余课继续在同一目录修改，日常不用重装。

## 下一次学习与暂停

```sh
npm run lab -- status
npm run lab -- start C03
npm run lab -- check C03
```

`start` 选择本课并显示文件、验收和启动入口，不替换代码。`check` 检查实际文件，不替你修复，也不修改当前页面的库存。暂停时把当前课、已改文件、观察结果、下一步写到 `notes/next.md`。

课程网页的“标记完成”保存在当前浏览器，与 `.lab/` 中的任务位置和本地检查分别管理。换浏览器前到[学习路线](/js_web/roadmap/)导出阅读进度；网站不会自动同步工作区源码或商品数据。

## 补课或恢复

平常继续自己的代码。需要补课才下载课内标明的起点，或在工作区执行：

```sh
npm run lab -- restore C02 ../inventory-recovery
```

这会把 C03 参考起点写入另一个新目录；目标非空时拒绝。先对照自己的修改，再决定是否搬回，不会自动重置作业。C00 是初始工程，Cnn 是完成该课的参考解，二者含义不同。

```sh
npm run lab -- compare C03
```

只读显示当前代码与 C03 完成参考解的差异，不会应用补丁。完整答案默认在课内折叠。下载绑定一个发行版；<WorkspaceDownload manifest />列出 C00 和各课完成快照的源码与包 SHA-256。包中含练习锁文件，不含依赖、缓存、个人数据或教师参考目录。

需要核对下载时，把本地 `.tar.gz` 的 SHA-256 与清单中对应课的 `archiveSha256` 比较；`sha256` 对应同名 `.json.gz`，两者不要混用。旧发行包仍保留在原版本地址，不能用它的校验值核对新版包。

## 从较早发行版继续

已用上一发行版时，先保留旧目录和自己导出的数据。把新的 C00 另存到新目录，保留新版 tools、依赖清单/锁和 adapter 机械外壳；迁入自己的 src、notes、tests 与 vite.config.js，自增的 package.json scripts 和已有 adapter 改动逐项合并。新目录执行一次 npm ci 后继续当前课；不搬旧 node_modules。先比较文件再搬移，正常升级不从完成参考解开始。

C23、C41 分别从正式 C22、C40 继续；恢复时按上表选择前置完成态，不用历史试做起点。来自较早版本的 L4 工程也要保留已完成的 adapter；迁入源码时先比较再合并，不用新的占位外壳覆盖自己的答案。

## 本地练习与在线阅读

课程网站部署在 `/js_web/`，学习包从带发行版的下载目录获取。Lab 应用在本地启动、构建和静态预览；默认生产演示路径 `/js_web/demos/inventory/` 是构建目标，不等于该地址已经部署在线应用。

库存使用静态数据、浏览器存储或浏览器内 mock。UI5 的四个名称、运行方式与资源要求见 [UI5 家族速查](/js_web/reference/ui5-family/)。
