一个工作区，从商品卡片到静态交付。每课接续你自己的修改；五个 Lab 是阶段产出，共用数据、规则和依赖。

## 第一次开始

使用 Node 24。在新目录下载并解压 <WorkspaceDownload label="C00 初始工程" />，或使用仓库的 `labs/inventory/`。解压文件位于当前目录，不要解压到已有作业里。

在库存工作区执行一次：

```sh
npm ci
npm run lab -- start C01
npm run lab -- dev
```

打开终端打印的地址，应看到「P001 机械键盘 · 库存 12 件」。启动脚本是提供好的骨架，工具原理在运行时与工程课解释。网站本身无需本地安装。

安装会下载 React、组件库与检查工具，用时取决于网络和缓存。首次使用 OpenUI5 时，UI5 CLI 还会下载对应框架资源。其余课继续在同一目录修改，日常不用重装。

## 下一次学习与暂停

```sh
npm run lab -- status
npm run lab -- start C03
npm run lab -- check C03
```

`start` 选择本课并显示文件、验收和启动入口，不替换代码。`check` 检查实际文件，不替你修复，也不修改当前页面的库存。暂停时把当前课、已改文件、观察结果、下一步写到 `notes/next.md`。

课程网页的“标记完成”保存在浏览器，与本地检查分别管理。

## 补课或恢复

平常继续自己的代码。需要补课才下载课内标明的起点，或在工作区执行：

```sh
npm run lab -- restore C02 ../inventory-recovery
```

这会把 C03 参考起点写入另一个新目录；目标非空时拒绝。先对照自己的修改，再决定是否搬回，不会自动重置作业。C00 是初始工程，Cnn 是完成该课的参考解，二者含义不同。

```sh
npm run lab -- compare C03
```

只读显示差异。完整答案默认在课内折叠。下载绑定一个发行版；<WorkspaceDownload manifest />列出源码与包的 SHA-256。包中含练习锁文件，不含依赖、缓存、个人数据或教师参考目录。

## 从较早发行版继续

已用上一发行版时，先保留旧目录和自己导出的数据。把新的 C00 另存到新目录，再把自己的 src 与 notes 搬入；保留新包的 tools、清单和锁，在新目录执行一次 npm ci 后继续当前课。先比较文件再搬移，正常升级不从完成参考解开始。

本版连续路线已接到 C36：C23 从正式 C22 继续，L3 从 C20 开始。C41 仍使用单独标明的试做起点；旧发行包继续可下载。

## 阶段路线

本次按依赖逐批改版；未接入的课保留旧版阅读和示例链接。试做起点会单独标明前置，不冒充已经连续完成前面的课程。
