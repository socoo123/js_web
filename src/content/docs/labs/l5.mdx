## 从哪里开始

继续 L4 自己完成的 C44 工程，**回到保留的 `src/react/` 主应用**，不把 UI5 React adapter 当成交付课的强制基础。公共 core、repository 与四个 adapter 都保留，不再新建一个最终项目。

需要补课或恢复时，将 <WorkspaceDownload checkpoint="C44" label="C44 起点包" />解压到新的空目录，执行一次 `npm ci`；也可在本发行版工作区执行 `npm run lab -- restore C44 ../inventory-delivery`，非空目标会被拒绝。旧版工程先按[升级说明](/js_web/labs/#从较早发行版继续)合并自己的源码与笔记，不搬旧依赖目录。

在工作区执行：

```sh
npm run lab -- start C45
npm run lab -- dev
```

`start` 只选任务，不改源码；这次入口应是 `src/react/index.html`。若仍看到 UI5 adapter，先 Ctrl+C 停止旧服务，再启动当前任务。安装、下载校验与恢复保护见[工作区入口](/js_web/labs/)。

先导出并保管个人快照，再按 C45 准备固定数据的 `baseline.json`。每次独立数字实验前导入这份基线，避免上一轮保存的 P004=8 或补货影响下一轮结果；实验后可以导回个人快照。不要清空整个浏览器存储。

## C46：预览已经构建的文件

先按 C46 在现有 `vite.config.js` 的配置对象中加入 `base: "/js_web/demos/inventory/"`，保留原有 source map 与 test 配置。然后在自己的 `inventory/` 执行：

```sh
npm run lab -- start C46
npm run lab -- build
LAB_STATIC_ROOT=dist/src-react node tools/static-react-server.mjs
```

打开 `http://127.0.0.1:8068/js_web/demos/inventory/`。这条命令只读已有 `dist/src-react`，不重新构建、不修正 base，也不将缺文件回退成首页。**保留 `LAB_STATIC_ROOT=dist/src-react`**：省略它会进入旧的重新构建冒烟模式，检查的就不是这一批已有产物。修改源码或配置后，先重新 build 再预览。

P004 的 hash 详情刷新应成功，干净详情路径 `products/P004/` 和缺失模块 `assets/missing.js` 则应返回真正 404。检查当前配置与源码时，先 Ctrl+C 结束手工预览，再运行 `npm run lab -- check C46`；后续 `check C47`、`check C48` 前也先停旧服务，避免占用默认 8068 端口。

## 收尾：能交付，也能说明为什么

每个数据场景从独立固定数据开始：初始 6 种商品、52 件、2634800 分。

1. P004 草稿 8 后取消，它仍为 3，清除筛选后全量总库存 52；保存 8 后只有它改变，清除筛选后全量 57，P001 仍为 12。筛选中的摘要统计可见结果。
2. 非法快照被拒绝，好数据原文不变；连续交互结果正确，提交失败后保留草稿并可重试。空白库存拒绝，0 合法。
3. 生产构建的 `/js_web/demos/inventory/` 下，入口、模块与静态数据可用，P004 hash 详情刷新成功；故意访问缺失资源应返回 404，而不是 HTML 200。
4. 从初始固定数据勾选“仅低库存”，URL 写入 `stock=low`，只显示 P004/P006，共 2 种、8 件、539200 分；1–5 件才算低库存，售罄 0 排除。条件与搜索/分类取交集，刷新保留，清除全部条件恢复 6/52/2634800；筛选本身不保存商品。P004 保存 8 后离开低库存结果，焦点回标题。
5. 只用键盘完成筛选、打开、输入、取消和保存；360/768/1280px 可读。现场增量有行为断言，浅复制故障的修复同时保护旧商品值与对象身份。
6. 按各课运行 `npm run lab -- check C45` 至 `npm run lab -- check C48`；四份 notes：`debug.md`、`delivery.md`、`test-plan.md`、`final-review.md` 写明实际证据、操作和结论。

站点路径是 `/js_web/`，库存应用的默认生产目标是 `/js_web/demos/inventory/`，磁盘工作区则是自己的 `inventory/`。课程网站与学习包在线发布；Lab 应用按 C46 在本地构建和预览，只有自己实际部署后才有对应在线演示。Pages 不提供 Node 服务、真实 SAP 后端或账号同步。
