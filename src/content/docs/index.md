## 为你的 Java 经验搭一座桥

你已会写程序，但不必提前掌握 HTML、CSS、浏览器或 TypeScript。课程从这些基础讲起，用 Java 熟悉的对象、集合、异常和工程经验帮助你理解 JavaScript 的不同之处。

**48 课主线已发布。** 从 C01 开始阅读，按[课程目录](./roadmap/)跟做，最后用 C48 的自测与补缺表安排复习。

## 两种学习节奏

| 路线 | 每日安排 | 适合你何时选择 |
| --- | --- | --- |
| 4 周主线 | 每周 6 天，每天 2 个微课与练习，共 24 天、48 课；每天 3–4 小时 | 能持续投入，希望连贯完成库存管理项目 |
| 8 周慢速与深化 | 每天 1 个微课，增加复习、调试与独立练习 | 希望消化新概念，或每天可用时间较少 |

## 每一课怎么学

1. 先看目标和 Java 对照，明确本课解决什么问题。
2. 运行代码，对照预期输出；标注「自己尝试」的部分有环境与步骤。
3. 做预测、修改和排错练习，再展开提示与答案。
4. 使用 DevTools、日志与测试解释结果，把知识接回库存管理小项目。

语言与数据结构、Node/Bun 运行时、npm/Yarn/pnpm 包管理器会分别讲清；之后深入 React，再学习开源组件与 SAP UI5 系列。

课程中的「已验证」表示示例实际执行过，「已核对」表示对照了资料，「未验证」表示尚未执行。练习主要在你自己的浏览器或本地工程中完成。
