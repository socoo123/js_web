## 2. 写法约定（C03/C15/C23 与以后各课共用）

- **页首**：改写后的课删除旧的 `> **第 N 周 · 第 D 天** …` 引用块，在 frontmatter 加：

  ```yaml
  lesson:
    time: 阅读跟做约 55 分钟 · 实作约 40 分钟
    prereq: JS 闭包、C21–C22 的 JSX 与 props
    env: 本地 React
    verified: all        # all = 示例已运行验证；partial = 部分示例未运行，已在对应位置标注
  ```

  周/天、所属 Lab 由 `LessonHeader` 从 catalog 读取。**有 `lesson` 字段即视为 V3 改写课**，lint 对它启用新规则。
- **先猜一猜**：

  ````mdx
  <Predict question="已售完的商品，两行分别打印什么？">

  ```js
  console.log(0 || 12);
  ```

  <div slot="answer">

  ```text
  12
  ```

  `||` 遇到任何 falsy 值都换成右边。
  </div>
  </Predict>
  ````

  子内容不缩进，代码围栏前后空行。答案区的 `summary` 由组件写为「揭晓答案」，不能用「提示」「参考答案」（这两个留给练习，check-build 计数）。
- **效果**：`<Effect kind="console|terminal" example="c03/defaults" caption="…" />`（读取 `examples/c03/defaults.expected.txt`），或不写 `example`、用子代码块；`<Effect kind="page" preview="c15/layout" caption="…" />`；`<Effect kind="demo" demo="c23-update-queue" caption="…" />`。
- **可运行片段**：`<RunSnippet example="c03/defaults" />`，只用于纯 JS 课，源码与预期输出都来自已由 `npm run examples` 核对的文件。
- **记住 / Java 对照**：段首写 `**记住：**` 或 `**Java 对照：**`，一段一句；样式由路 1 的插件按段首识别。「自己尝试」仍用 `:::tip[自己尝试 · 环境]`。
- 组件只接受静态字符串属性；新组件属性白名单见 `scripts/lesson-sources.mjs`。
- **锚点保留**：改写课保留现有全部 `id`（标题改了就加 `<a id="旧锚点"></a>`）。C03：`1-值有类型输入框给的是文本`、`2-number整数分与-bigint`、`3-文本先转换再校验`、`4-默认值库存-0-必须保留`、`5-比较类型内容与身份`、`补货得到-123`、`唯一任务接通可靠的补货入口` 及旧兼容锚点；C15：`1-盒模型决定实际占用的空间`、`2-flex-排工具栏grid-排卡片`、`3-移动优先媒体查询逐步增加列数`、`4-焦点与反馈也属于可用布局` 及旧兼容锚点、各小节锚点；C23：`1-用-state-记住界面需要的值`、`2-一次渲染的值是固定的`、`3-批处理与更新队列`、`4-延迟补货要基于执行时的待更新值`、`5-完成事件入口保持-hooks-顺序`、`连续补三件只有-13`、`唯一任务让-p001-的补货顺序正确` 及旧兼容锚点。Lab 页与总览的现有锚点同样保留。

## 3. 组件接口

| 组件（负责路） | Props | 输出约定 |
| --- | --- | --- |
| `LessonHeader`（1） | `lessonId`、`lesson`（frontmatter 对象） | 根元素 `data-lesson-header`；静态显示周/天、时长、前置、运行环境、验证状态、所属 Lab |
| `LabBar`（3） | `lessonId` | 根元素 `data-lab-bar`；所有课都渲染；无 JS 时是指向 Lab 页（有步骤时指向步骤锚点）的静态链接；带 `?from=<stepId>` 时浮出「返回 L3 第 N 步」 |
| `LabNext`（3） | `lessonId` | 页底「回到 Lab 下一步」与完成按钮；内部渲染且只渲染一次 `LearningProgress` |
| `LabSteps`（3） | `labId` | 渲染 `labs/steps/<lab>.json`；每步根元素 `id="step-<stepId>"`；无 JS 时全部可读、隐藏勾选 |
| `Predict`（2） | `question`，默认 slot、`answer` slot | 根元素 `data-predict`；无 JS 用原生 details |
| `Effect`（2） | `kind`、`example`/`preview`/`demo`、`title`、`caption` | 根元素 `data-effect`；`page` 缺截图时输出 `data-missing-preview` 占位 |
| `RunSnippet`（2） | `example`、`title` | 根元素 `data-run-snippet`；`sandbox="allow-scripts"` 的独立 iframe、2 秒超时、可编辑/重置/对比预期；无 JS 显示已验证输出 |
