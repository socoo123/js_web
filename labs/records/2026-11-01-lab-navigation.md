# Lab 导航与网页规则维护

2026-11-01。用户要求 Lab 在网站导航中直接可见，任务、业务规则和验收要求必须写在网页，不能只保存在源码或仓库文档中。本次属于改版完成后的定点维护。

## 改动

- 侧栏新增默认展开的「Lab 实验」分组，直接列出工作区、规则页和 L1–L5；手机菜单使用同一导航。
- 新增 `/js_web/labs/rules/`：固定数据、字段类型与范围、补货/编辑、草稿/取消/保存、查询/统计、导入/恢复、各阶段预期结果和检查命令。
- 五个 Lab 页面开头补充面向学员的阶段任务与规则；首页、工作区、48 课任务卡与 README 接入规则页。任务卡也能直接进入所属 Lab，并区分下载后的 `inventory/` 与仓库内路径。
- CONTENT_GUIDE 固定“需求写进网页、导航直达五个 Lab”的写作要求。现有全站浏览器检查的页面数由 61 改为 62，纳入新页面。
