# 已发布的不可变学习包

此目录保存实际 Pages 发布的包和 manifest，保留逐字节 SHA-256。构建会继续复制旧发行版，旧下载地址不会因后续迁移失效。

- `2026.10-v2.1`：三课试做发行版，提交 `11259e9`，Pages run `40684581291`。从线上下载并逐包核验，共 8 个快照、JSON/gzip 与 tar/gzip 两种格式。
- 教师修改已发布快照的源文件或工具时必须升发行版；`build:labs` 会拒绝在同一版本下改写。新发行版的课内起点仍接续上一课；旧学习包不静默升级。

这里是可重建源码的发行包，不含 node_modules、dist、缓存、凭据或个人作业。
