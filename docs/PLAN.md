# Java → JavaScript 学习网站总计划

规划日期：2026-10-15。恢复关键词：**JS_WEB_START**。

用户基础：会 Java，有编程经验，尚未系统学习 JavaScript 与前端。每天可投入 **3–4 小时**，预计用 **1–2 个月**完成。

本轮交付是远程关联、课程与网站规划、持久化续做入口。网站实现从后续 M1 开始。

用户补充：不需要每个教学示例都在站内完整运行，需要自己操作的内容明确标注；必须补充前端调试工具与 UT 框架。

## 1. 学完后要能做什么

1. 讲清 JavaScript、ECMAScript、引擎、浏览器、Node、Bun 与包管理器分别解决什么问题。
2. 读懂现代 JS，正确使用类型、作用域、函数、闭包、this、原型、模块和异步。
3. 根据业务选择 Array、Object、Map、Set 等结构，能实现基础栈、队列、树遍历并判断常见操作的成本。
4. 理解浏览器页面、事件、请求和存储；能用 DevTools 定位问题。
5. 用 Node + npm 建立可复现的项目，读懂 package.json、锁文件、依赖树和构建输出；理解 Yarn/pnpm/Bun 的选择差异。
6. 用 React 完成组件拆分、表单、状态流、数据请求、路由、异常处理与有意义的测试，解释 Effects 为什么需要或不需要。
7. 区分 SAP 的几套 UI 技术，并完成经典 OpenUI5 与 React + UI5 Web Components 的最小业务示例。
8. 能比较主要开源组件体系，并把一个静态前端应用交付到 GitHub Pages。
9. 能使用断点、Network、React DevTools 和测试失败信息定位问题，并用 Vitest/RTL 编写核心行为测试，理解 Jest 与 Playwright 的定位。

目标是建立正确心智模型并能独立实现小应用。高级算法、完整 SAP 后端、复杂 SSR 与大型企业架构放在选修与后续路线。

## 2. 学习时间预算

主线为 **4 周 × 每周 6 天 = 24 天**，每天 2 个微课，共 48 课。总预算 **72–96 小时**。

每天建议安排：

| 环节 | 时间 | 要做的事 |
| --- | --- | --- |
| 复习 | 15 分钟 | 不看答案复述上一日的关键机制，重做一个易错例子 |
| 两个微课 | 70–90 分钟 | 阅读、运行、改变输入、比较 Java 与 JS 行为 |
| 编码练习 | 60–75 分钟 | 完成两课的必做练习并解释输出 |
| 项目与笔记 | 35–60 分钟 | 把今日概念用于库存应用，记录错误和纠正方法 |

合计 180–240 分钟。每周第 7 天休息或补课；如果一天未达到验收标准，顺延一天，保留语言与 React 的核心练习。

### 4 周主路线

| 周 | 课号 | 学习重点 | 交付物与验收 |
| --- | --- | --- | --- |
| 第 1 周 | C01–C12 | 历史、Web 基础、JS 类型/函数/对象、集合和结构、DOM、异步起点 | 纯 JS 库存数据模块：查找、排序、去重、分组；解释闭包与一段事件循环输出 |
| 第 2 周 | C13–C24 | async/fetch、现代 ES、模块、Node、包管理、构建；React 入门 | 原生 JS 页面 v1；Node 数据处理脚本；React 商品列表与计数/筛选 |
| 第 3 周 | C25–C36 | 详细 React：表单、状态、Context/Reducer、Ref、Effect、请求、路由、Hooks、现代 API、测试 | React 库存应用 v2：增删改查、校验、详情、持久化、错误/空/加载状态和关键测试 |
| 第 4 周 | C37–C48 | 开源组件选型、经典 UI5、UI5 Web Components、静态部署、综合验收 | 同业务的组件库版与 UI5 最小版；完成并解释 Pages 静态交付 |

React 独立安排 16 课，约占课程三分之一；它需要用 JS、Web 与异步知识贯穿练习，不能只讲 Hook API 名称。

### 8 周节奏

同一套 48 课拆为每天 1 课、每周 6 天：

| 周 | 课号 | 重点 |
| --- | --- | --- |
| 1 | C01–C06 | 历史、Web、类型、对象、函数 |

如果仍每天学 3–4 小时，额外时间用于重写练习、TypeScript、小型 Node API、本地 SAP/OData 实验和选修，不再重复增加必修课。

## 3. 贯穿项目：库存管理小应用

使用同一业务领域降低重复理解成本。商品包含 id、名称、分类、库存量和价格；价格在业务示例中用整数分保存，顺便讲浮点数边界。

1. **数据模块**：JS Array/Map/Set，实现筛选、排序、分组、库存统计与输入校验。
2. **原生页面**：DOM 事件、静态 JSON 请求、列表与表单、localStorage；用浏览器查看请求与错误。
3. **Node 工具**：读取本地样例文件、生成统计报告；这在学习者本地或构建环境执行。
4. **React 应用**：列表、搜索、编辑、详情、路由、异步状态、可复用 Hook 与关键测试。
5. **组件库对照**：选 Ant Design 完成表格与表单；另提供 MUI/shadcn/ui 等同需求的简短对照。
6. **UI5 最小应用**：OpenUI5 XML View + Controller + JSONModel；另做 React + UI5 Web Components 表单/列表，比较开发模型。
7. **静态交付**：本地数据增删改查、导入导出、可访问性、移动阅读与部署验收。

Pages 演示中的增删改查是当前浏览器本地数据行为。真实多人数据、鉴权、SAP 系统与持久化后端另需服务，课程会标明边界。

## 4. 课程的教学方式

- 每个主题先提出真实问题，再用能运行的最小代码解释。
- 通过 Java 对照帮助迁移，同时明确类比的边界，例如 Java Stream 与 Array.map、HashMap 与 Map。
- 核心结构：前置知识 → 目标 → Java 对照 → JS 机制 → 完整代码及输出 → 易错例子 → 练习 → 分步答案 → 项目应用 → 官方来源。
- 每课至少 1 个必做练习；核心难点增加输出预测或修错练习。扩展题明确可跳过。
- 数据结构讲“什么时候用、怎样实现、复杂度和边界”，不将课程变成刷题集。
- 现代特性按解决的问题与环境支持组织，年度版本表作为速查，不背完整变更列表。
- 第 1 课提供历史故事；后续在模块、异步、Node、React 与 UI5 中延续技术为何变化的故事。
- 每个代码示例标明环境：浏览器、Node 或 React 构建项目；不可省略必要文件、依赖和运行方法。
- 需要学员动手的例子标注「自己尝试」，提供步骤与预期结果；不要求全站有完整在线运行环境。
- 调试从第 1 周开始，第 2 周引入 UT 与回归测试；详细路线见 [调试与测试](DEBUG_TESTING.md)。

详细要求见 [教学规范](CONTENT_GUIDE.md)；每课安排见 [课程大纲](CURRICULUM.md)。

## 5. 网站产品规划

网站是可阅读、可练习、可回查的中文课程站。

必需页面与功能：

1. 首页：适合谁、4 周/8 周入口、当前学习位置、课程与项目入口。
2. 学习路线：按周、按主题查看；课号稳定，显示前置要求、预计时间和必修/选修。
3. 课程页：左侧章节导航、正文、桌面页内目录、上一课/下一课、代码复制、答案折叠。
4. 练习与示例：讲解代码、完整必要文件或清楚标记的 TODO、「自己尝试」操作步骤与预期结果；少量在线演示按教学需要提供。
5. 速查页：Java↔JS 对照、Array/Object/Map/Set 选择、异步顺序、运行时/工具关系、React Hooks、UI5 家族。
6. 静态全文搜索：中文概念和英文 API 均能定位课程。
7. 本地学习进度：完成标记、最近阅读、刷新恢复；提供进度 JSON 导入导出。
8. 来源与更新说明：核验日期、测试版本、标准与提案状态。

阅读优先：正文是构建生成的 HTML，关闭 JS 也能查看代码和答案。手机上正文不横向溢出，代码块独立滚动。无需注册或服务器数据库。

第一版以阅读和本地尝试为主，可提供少量预构建演示；任意代码在线编辑器列为后续增强。

## 8. 验收清单

- [ ] 48 个微课都有目标、前置知识、代码、练习与答案，不只有大纲；需自行运行的内容有「自己尝试」标注。

## 9. 明确的范围与后续扩展

主线网站无后端，不要求账号、云数据库、支付、CMS 或在线完整 IDE。React Server Components、SSR、Next.js、完整 SAP BTP/CAP/ABAP 接入、复杂状态管理与性能基准测试作为后续选修。

先把语言基础、React、组件与静态交付学扎实。4 周路线较紧，未通过练习时使用 8 周节奏；2 个月目标仍是完整覆盖与可独立做小应用，而非所有生态工具的专家程度。
